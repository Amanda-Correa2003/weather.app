Aplicativo do Tempo 🌤️

Aplicação web desenvolvida em JavaScript puro para consultar a previsão do tempo de qualquer cidade em tempo real, utilizando a API do OpenWeather. 

O projeto foi construído com foco em ter uma interface moderna, responsiva e agradável, servindo como uma ótima adição para o portfólio.

Tecnologias Utilizadas

* HTML5 (com marcação semântica)
* CSS3 (Flexbox, Grid, Variáveis e responsividade com Media Queries)
* JavaScript (Assíncrono com `async/await`, manipulação do DOM e Fetch API)
* API OpenWeather (Dados meteorológicos atuais e previsão de 5 dias)
* FontAwesome (Ícones)
* Google Fonts (Fonte Inter)

Funcionalidades

* Busca por cidade: Pesquisa rápida pressionando `Enter` ou clicando no botão de busca, com tratamento de espaços em branco.
* Clima atual: Exibição de temperatura atual, máxima, mínima, sensação térmica e descrição do clima com ícones dinâmicos.
* Detalhes meteorológicos: Informações adicionais como umidade, velocidade do vento, pressão atmosférica, visibilidade e horários de nascer e pôr do sol.
* Previsão estendida: Cards com a previsão do tempo para os próximos dias.
* Tratamento de estados: Mensagens amigáveis na interface para erros de busca, carregamento e avisos iniciais (sem depender de alertas do navegador).
* Design responsivo: Layout adaptado para diferentes tamanhos de tela (smartphones, tablets e desktops).

Como Executar o Projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Certifique-se de manter os arquivos `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize uma extensão como o Live Server (no VS Code) para rodar o projeto localmente.
